# Security policy

## Reporting a vulnerability

Please do not open a public issue containing details of a security vulnerability. Until a private reporting channel is published, contact the repository owner privately through the contact method listed on the repository hosting profile.

Include the affected revision, macOS and Swift versions, reproduction steps, and the possible impact. Do not include real disk identifiers, serial numbers, or user data in a public report.

## Scope

The main security concern is preventing a disk test from writing to the wrong device or overstating what its observations prove. The current repository is pre-alpha; its CLI and macOS safety integration are incomplete. Do not use it on real storage.
